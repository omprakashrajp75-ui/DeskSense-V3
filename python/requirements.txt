# No hardware-compatible replacement exists in App Lab's Brick catalog.
# See README for the fallback approach: bbox-proxy posture + OpenCV DNN
# (standard conv-net ops, not MediaPipe) for gaze.

# UV_CONSTRAINT. Listing any opencv-python-headless version here makes uv try

# causing an unsatisfiable-dependency failure. The pre-installed build
